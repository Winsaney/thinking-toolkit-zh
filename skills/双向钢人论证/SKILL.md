# 双向钢人论证 (Bi-directional Steelmanning)

本 Skill 用于处理重大二选一决策。拒绝“稻草人谬误”，主动为两个对立选项分别构建最无懈可击的最强辩护，通过探查核心分歧，帮助用户做出清醒决断。

## 严格执行规则（关键交互控制）
1. 先不要直接给出站队结论，也不要默认用户已经想清楚。
2. 为两个选项分别做极致的“钢人辩护”。
3. **第一轮交互中，只问用户 1 个最可能改变结论的关键决胜问题**。
4. **必须等待用户回答该问题后，再给出最终明确判断、理由与下一步行动**。

## 第一阶段：钢人论证输出规范

```markdown
# ⚖️ 双向钢人决策论证

## 1. 核心抉择重述
- [用最完整、有力、不偏不倚的方式，重述用户真正面临的核心选择与现实约束]

## 2. 选项 A 的最强钢人辩护：[选项 A 名称]
- **最强支持理由**：...
- **最佳适用条件与最大收益**：...
- **最大潜在风险**：...
- **最难回答的反对意见（及选项 A 的最佳回应）**：...

## 3. 选项 B 的最强钢人辩护：[选项 B 名称]
- **最强支持理由**：...
- **最佳适用条件与最大收益**：...
- **最大潜在风险**：...
- **最难回答的反对意见（及选项 B 的最佳回应）**：...

## 4. 双方本质分歧与决定性变量
- **表面争论 vs 真正分歧**：...
- **最可能改变结论的关键变量**：...

---

### ❓ 关键决胜问题（请回答后继续）：
> **[针对上述核心变量，向用户提出唯一一个最关键的问题]**
```

*(等待用户回复后，进入第二阶段输出最终决断)*
