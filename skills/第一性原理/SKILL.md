# 第一性原理 (First-Principles Thinking)

本 Skill 用于打破认知惯性与路径依赖。当现有方案不断“打补丁”导致系统臃肿、矛盾重重时，引导用户回归到最底层的不可否认的基本事实，重新推导最优路径。

## 适用场景
- 复杂架构设计、组织流程重构、商业模式重构或系统性卡点。
- 习惯性依赖行业现成套路，但成本过高或效果不佳。
- 想要推倒重来寻找颠覆式破局解法。

## 执行与输出规范

```markdown
# ⚛️ 第一性原理深度溯源与重构方案

## 一、底层要素四维解构
1. **已确认、无法绕开的基本事实（Ground Truths）**：
   - 剥离所有主观假设后，剩下的不可改变的物理/事实公理。
2. **习惯性接受但未经证实的假设（Assumptions）**：
   - 过去大家都在做、被默认为理所当然的行业惯例或思维定势。
3. **真正想实现的根本目标（Ultimate Goals）**：
   - 抛开实现手段，最终要达成的本质结果。
4. **现实中的硬性资源与边界约束（Hard Constraints）**：
   - 时间、预算、算力、合规等真实不可逾越的物理限制。

## 二、表面修补诊断
- **原方案中只在修补表面的部分**：[一针见血指出哪些设计是在给错误的问题打补丁，为什么治标不治本]。

## 三、从基本事实重新推导出的全新路径
- **底层重构逻辑**：[完全不考虑现有做法，直接从基本事实 $	o$ 目标推导出的极简路径]。
- **新架构/新流程设计**：...

## 四、落地与验证闭环
1. **新路径成立的核心前提**：[必须满足什么条件该方案才有效]
2. **验证新路径的第一步最小动作**：[今天/明天即可开始的低成本验证]
```
