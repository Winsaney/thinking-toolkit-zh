# 事实核查与论证审计 (Fact-Checking & Logic Audit)

本 Skill 基于笛卡尔批判性审视框架，将复杂论述拆解为事实、推论与价值判断，利用网络搜索验证事实真伪，并审查推理链条的逻辑严密性。

## 执行流程
1. **成分三拆解**：
   - 可被外部独立验证的事实（数据、发生事件、时间线）；
   - 从事实推导出的结论与推论；
   - 掺杂其中的主观价值判断与情绪色彩。
2. **联网核查事实**：
   - 使用当前宿主提供的网页搜索或 URL 读取能力，核对数据原始来源、样本量、发布时间与完整上下文。
   - 标注事实状态（已证实 / 基本成立但需收窄 / 存在争议 / 证据不足 / 明显错误）。
3. **逻辑推理审计**：
   - 事实能否充分推出结论？
   - 隐藏了哪些未经验证的隐含假设？
   - 是否存在相关性混淆为因果性？
   - 是否刻意遗漏了相反证据或替代解释？
   - 结论在何种边界条件下成立，何时失效？

## 输出规范

```markdown
# 🔎 事实核查与论证审计报告

## 1. 事实核查清单
| 提取的事实陈述 | 核查状态 (5级评定) | 溯源核查说明与上下文 |
| :--- | :--- | :--- |
| [陈述 1] | **已证实 / 存在争议 / 明显错误...** | [简述一手来源与背景] |

## 2. 推理链条漏洞审计
- **未经验证的隐性假设**：...
- **逻辑跳跃与因果谬误**：...
- **被忽略的相反解释与关键信息**：...

## 3. 边界条件与失效场景
- 该结论在 [条件 A] 下成立；当出现 [条件 B] 时彻底失效。

## 4. 补强后的最合理版本
- [去伪存真、补全边界后，客观严谨的表述版本]

## 5. 最终可信度评定
- **置信度评级**：[高 / 中 / 低 / 不可信]
- **核心建议**：目前可以相信到什么程度，建议采取的态度与核验行动。
```
