# 重力问题辨析与真问题重构手册

在斯坦福人生设计课中，创始人比尔·伯内特常说一句话：
> **“如果你面对的是重力，那就不叫问题。因为你无法解决重力，你只能接受重力。”**

---

## 一、什么是“重力问题”（Gravity Problems）？

**重力问题**指的是那些**客观存在、无法由个人主观意愿或短期努力直接改变的现实环境与法则**。

### 典型重力问题清单：
1. **生理与自然规律**：年龄增长、需要睡眠、身体机能退化、人类寿命极限。
2. **宏观行业与市场现实**：某传统行业正在整体萎缩、大模型普及导致初级岗位被替代、全球宏观经济周期。
3. **他人独立的意志与选择**：前任不爱你了、老板固执己见、父母的传统观念。
4. **既成事实的历史**：高考成绩、过去的职业断层、曾经失败的创业经历。

### 陷入重力问题的典型征兆：
- 反复抱怨“为什么现在的环境这么差”、“为什么我今年已经 35 岁了”、“为什么公司领导不能开明一点”。
- 把无法行动归咎于重力：“因为行业不行了，所以我什么都做不了。”

## 二、如何将“重力问题”重构为“可设计的真问题”？

### 转换公式：

| 原始抱怨（纠缠重力） | 核心重力（坦然接受） | 重构后的可设计真问题 |
| :--- | :--- | :--- |
| “我今年 38 岁了，大厂招聘只要 35 岁以下，我该怎么去大厂面试？” | 大厂招聘名额受年龄门槛限制是客观用人机制。 | “在拥有 15 年行业经验的背景下，我如何通过顾问合作、合伙人或细分领域出海，将经验转化为溢价？” |
| “我所在的传统出版业快完蛋了，我深爱图书编辑工作，怎么让这个行业复兴？” | 纸质出版物受数字化冲击是不可逆的媒介演进趋势。 | “如何利用我出色的内容策划与选题审美，在播客、独立知识产品或数字策展领域重新建立受众连接？” |
| “我父母强烈反对我换工作，我怎么才能让他们完全理解并支持我？” | 父母的认知模型基于过去的生存经验，无法被单向说服。 | “我如何在不强求父母立即理解的前提下，保持财务独立并完成 3 个月的业余试水，用现实成果建立信心？” |
| “我没有启动资金，怎么能去创业开一家属于自己的咖啡馆？” | 缺乏数十万现金储备是目前的硬性物理约束。 | “在 0 启动资金下，我能否先借用朋友周末闲置的吧台举办 3 次快闪咖啡沙龙，验证我的调配手艺与客群口碑？” |

## 三、Agent 提问与引导原则

在 Phase 1 的焦虑甄别阶段，当 Agent 识别出用户的回答属于重力问题时：
1. **不要冷酷说教**：首先共情用户的无力感与挫败感；
2. **温和点破边界**：用类比（如“这就像抱怨地心引力让我们跳不高一样”）帮助用户看清不可改变的边界；
3. **转移聚光灯**：将用户的注意力从“无法改变的外部巨石”，重新拉回“自己手中的刻刀”，一起拟定新的真问题。
