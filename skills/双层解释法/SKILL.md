# 双层解释法 (Two-Tier Explanation)

本 Skill 用于解决“只听懂比喻却不懂底层机制”或“术语太硬完全看不懂”的学习痛点。通过生活化通俗层与严谨专业层的对照，帮助用户建立完整立体的认知。

## 适用场景
- 学习技术架构、计算机底层原理、金融概念、数学/物理理论等晦涩知识。
- 编程或研发中遇到陌生的协议、概念或术语。
- 需要向非专业人士解释复杂技术，或需要从概念理解跃升至机制掌握。

## 执行与输出规范

请按照以下四部分结构进行完整输出：

```markdown
# 💡 [概念名称] 双层深度解析

## 第一层：小白版（生活化视角）
- **通俗比喻**：用一个完全不脱离生活的直观类比（如做菜、快递、搭积木等）。
- **具体场景**：讲述一个具体的生活例子，让毫无背景知识的人也能直观感知它是怎么运转的。

---

## 第二层：专业版（技术/机制视角）
- **核心定义与精准术语**：使用行业标准术语明确定义。
- **底层运转机制**：讲清模块交互、数据流转或内部逻辑链条。
- **适用边界与失效条件**：在什么场景下适用，什么极端情况下会失效或有副作用。
- **常见误区辨析**：业界或初学者最容易产生的认知误区是什么。

---

## 📊 术语与认知对照表
| 小白通俗说法 | 专业精准术语 | 核心对应机制 |
| :--- | :--- | :--- |
| [通俗描述 1] | [专业术语 1] | [对应本质机制] |
| [通俗描述 2] | [专业术语 2] | [对应本质机制] |

---

## ⚠️ 我最容易理解错的地方
- [指出 1-2 个最隐蔽、最容易混淆的理解偏差，以及正确的矫正逻辑]

---

## 🎯 检验理解的 3 个问题
1. **基础题**：[考察是否真正分清基本机制]
2. **边界题**：[考察是否了解该概念的适用前提与局限]
3. **应用题**：[考察能否在实际场景中正确识别或运用]
```
