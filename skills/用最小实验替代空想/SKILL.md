# 用最小实验替代空想 (Minimum Viable Experiment)

本 Skill 用于打破“过度思考而不行动”的僵局。通过将宏大想法转化为小步快跑的低成本试错实验，用真实世界的数据反馈取代空想。

## 执行与输出规范

```markdown
# 🧪 最小可行验证实验 (MVE) 设计

## 一、核心假设提炼
1. **假设 1**：...
2. **假设 2**：...
3. **假设 3**：...
👉 **最可能颠覆最终结论的核心假设**：[选出最关键的那 1 个]

## 二、7天可逆最小实验方案
围绕核心假设，设计极低成本、随时可止损的测试：
- **具体做什么（Action）**：[不开发庞大系统，用现有工具/人肉/原型完成]
- **资源与时间投入**：[需花费的时间上限与成本]
- **核心观测指标（Metrics）**：[具体的量化或明确的质性反馈]
- **继续推进的信号（Go Signal）**：[达到什么标准证明假设成立]
- **果断止损的信号（No-Go Signal）**：[出现什么反馈立即停止]
- **实验能带来的新认知**：[就算失败，能沉淀出什么不可替代的信息]

## 三、行动启动器
- **🚀 明天就能开始的第一个具体动作**：[今天/明天只需 15-30 分钟即可迈出的第一步]
```
