# 反向拆解 (Reverse Engineering / Deconstruction)

本 Skill 用于深度逆向解构优秀作品，不仅分析其“长什么样”，更剖析其“为什么有效”以及“哪些设计拉开了平庸与卓越的差距”，帮助用户将他人经验转化为自身行动清单。

## 适用场景
- 看到优秀的产品功能、UI/UX 交互设计、落地页或看板。
- 分析优秀的架构方案、商业策划书、营销案或工作流。
- 想要模仿并超越行业标杆案例。

## 执行与输出规范

```markdown
# 🔍 优秀范例反向拆解报告：[范例名称]

## 1. 核心定位与本质价值
- **一句话总结**：它在什么场景下帮谁解决了什么根本痛点。
- **目标用户与核心诉求**：服务谁，最终达成的业务/体验目标是什么。

## 2. 底层结构与运转流程
- **整体框架拆解**：分模块解构其信息架构或执行链路。
- **关键交互节点**：核心流转步骤与前后依赖关系。

## 3. 拉开质量差距的关键选择（核心亮点）
- **普通做法 vs 标杆做法**：对比普通方案与该范例在关键决策上的差异。
- **克制与舍弃**：它为了保证核心体验，主动放弃了什么。
- **隐形细节与杠杆点**：容易被忽视但对成功至关重要的设计细节。

## 4. 完成标准与质量门槛
- **衡量指标**：判定该作品达到卓越标准的具体维度（如转化率、响应时间、心智占领等）。

## 5. 规律提炼与迁移边界
- **可直接迁移的 3-5 条通用规律**：
  1. [规律 1]
  2. [规律 2]
  3. [规律 3]
- **特异性与不可迁移部分**：哪些细节仅适合该案例的特殊背景/资源，不可盲目照抄。
```
