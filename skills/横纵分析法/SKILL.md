# 横纵分析法 (Cross-Longitudinal Deep Analysis)

本 Skill 采用经典的横纵双轴框架进行可追溯的深度研究。纵轴看历史演进与路径依赖，横轴看竞品差异与生态位，双轴交叉推演未来可能演变。

## 严格证据与工具调度规则
1. **优先一手来源**：遇到未核实信息必须调用 `search_web` 或 `read_url_content` 查证官方白皮书、财报、论文、权威访谈与原始数据。
2. **严禁混淆**：事实、推论和观点分开表述；重要结论就近标注来源与时间。
3. **冲突并列**：遇到相互冲突的数据时并列呈现，找不到证据时明确写“暂未核实”。

## 执行与研报输出结构

```markdown
# 📈 [研究对象] 横纵深度研究报告
*研究截止时间：[执行当天日期]*

## 一、核心结论 (Executive Summary)
- 300字内提炼研究对象的核心价值、当前生态位与终极判断。

## 二、关键时间线与纵向演化（纵轴）
1. **诞生背景与初心**：在什么技术/市场背景下诞生，关键推动者是谁，最初解决什么需求。
2. **关键转折与演进历程**：经历了哪些重要技术跃迁、战略转折、重大成功与挫折。
3. **历史沉淀的双刃剑**：
   - 沉淀为今日的核心能力：...
   - 演变为今日的路径依赖与历史包袱：...

## 三、横向对比与竞争格局（横轴）
1. **对比基准选择**：选取最具代表性的 2-3 个竞品/替代方案，并阐述选择理由。
2. **多维横向对比表**：
| 维度 | [研究对象] | [竞品 A] | [竞品 B] |
| :--- | :--- | :--- | :--- |
| **核心优势** | ... | ... | ... |
| **致命短板** | ... | ... | ... |
| **独特生态位** | ... | ... | ... |
3. **市场选择逻辑**：客户为什么选择它，又在什么场景下不得不放弃它。

## 四、双轴合流：底层驱动力剖析
- 历史形成的能力、约束与当前竞争态势结合，正在形成何种势能。

## 五、未来推演：最可能出现的 3 条路径
1. **路径一（基准乐观情景）**：[演进路径、前提条件、预警信号]
2. **路径二（阻滞中性情景）**：[演进路径、前提条件、预警信号]
3. **路径三（颠覆悲观情景）**：[演进路径、前提条件、预警信号]

## 六、仍待确认的关键问题与盲区
- [列出当前公开数据无法完全覆盖的 2-3 个疑点]
```
