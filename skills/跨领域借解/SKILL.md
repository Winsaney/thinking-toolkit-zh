# 跨领域借解 (Cross-Domain Solution Transfer)

本 Skill 建立在“人类大部分难题在另一个遥远的领域早已有成熟解法”的理念上。通过抽象问题底层结构，跨界寻求解法迁移。

## 执行流程
1. **去术语抽象**：剥掉行业黑话，提炼出人类在其他领域也会遇到的通用矛盾模型。
2. **三域机制检索**：从历史案例和至少 3 个彼此距离极远的领域（如生物进化、军事战役、建筑学、操作系统、航空航天、心理学等）寻找成熟机制。
3. **迁移翻译**：将跨界机制重新翻译回用户的实际场景中。
